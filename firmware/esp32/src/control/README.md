# Control Layer

Implementiert alle Regelalgorithmen für Bewegung und Stabilität.

## Inhalte

- PID-Regler für Geschwindigkeit
- Drehmoment-/Differentialsteuerung
- Stabilisierung

## Beispielklassen

- `PIDController`
- `WheelVelocityController`
- `MotionController`

## Ziel

Stabile, präzise Bewegung des Roboters in Echtzeit.
